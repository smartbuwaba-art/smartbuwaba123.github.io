# Smart Buwaba Android App — V44

Android Studio project wrapping the V44 Smart Buwaba web app as a native Android WebView app.

- Application ID: com.smartbuwaba.app
- Version: 44.0 (code 44)
- Target SDK: 35
- Local web app bundled in app/src/main/assets/index.html
- Internet, camera, microphone and file chooser enabled for the app features.

Open this folder in Android Studio, let Gradle sync, then use Build > Generate Signed App Bundle / APK to create the Play Store `.aab`.
