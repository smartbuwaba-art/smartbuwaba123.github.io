SMART BUWABA APP V20 — SOCIAL + VOICE FIXED

This package keeps the V19 social features and fixes the WhatsApp-style voice notes.
Voice notes use the browser microphone, upload through the existing Cloudinary unsigned preset, save the audio URL in Firestore, and render with play/pause, waveform animation, duration, and playback speed controls.

Use the Vercel Production deployment over HTTPS so microphone permission works. Never place the OpenAI API key in the browser or GitHub.
