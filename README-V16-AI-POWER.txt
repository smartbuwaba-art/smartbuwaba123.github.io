SMART BUWABA APP V16 — AI POWER EDITION

Added:
- Smart Buwaba AI creative quick actions: captions, video ideas, hashtags.
- Browser voice input (Chrome/Edge supported where SpeechRecognition is available).
- AI voice replies using browser speech synthesis.
- Optional secure AI backend URL setting. The browser sends {message, language, app} to the endpoint and accepts reply/message/text JSON.
- No API secret is stored in the app.
- Existing computer photo/video posting and Cloudinary configuration are retained.

IMPORTANT:
The app includes a local assistant fallback. For a true cloud LLM, deploy a secure backend endpoint and enter its URL in Settings → AI Assistant. Keep provider API keys on the server, never in index.html.
