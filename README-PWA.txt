SMART BUWABA TV - APP INSTALL

This version is a Progressive Web App (PWA).

How users install it:
- Android Chrome: open the website over HTTPS, then use the browser menu and choose "Install app" or "Add to Home screen" when offered.
- iPhone/iPad Safari: Share -> Add to Home Screen.
- Windows/desktop Chrome or Edge: use the install icon in the address bar or browser menu when available.

Important: the site must be served over HTTPS (GitHub Pages is suitable). PWA installation cannot be fully enabled from a file:// URL.

This does not create a native APK by itself; it makes the website installable like an app. A later Android/iOS wrapper can package the same web app as a store app if desired.

CHAT BUWABA ON WINDOWS / PC
- Open https://smart-buwaba-ai-app.vercel.app/ in Chrome or Microsoft Edge.
- Use the install icon in the address bar, or browser menu -> Install Chat Buwaba (if offered), to create a standalone app window.
- Allow microphone access when prompted to use voice typing or Voice Studio.
- The installed PWA can be used as a desktop app, but normal browser PWAs cannot display a floating bubble above every other Windows application or keep the microphone listening after the app is closed. That requires a separate signed Windows desktop application with explicit microphone controls.

ANDROID FLOATING B
- In Chat Buwaba, enable Floating B and allow "Display over other apps".
- The floating B shortcut stays available when you leave the app. Tap it to reopen Chat Buwaba and start voice input; Android will show its microphone permission / privacy indicator as applicable.
- The floating shortcut itself does not secretly listen in the background.
