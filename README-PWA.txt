SMART BUWABA TV - APP INSTALL

This version is a Progressive Web App (PWA).

How users install it:
- Android Chrome: open the website over HTTPS, then use the browser menu and choose "Install app" or "Add to Home screen" when offered.
- iPhone/iPad Safari: Share -> Add to Home Screen.
- Windows/desktop Chrome or Edge: use the install icon in the address bar or browser menu when available.

Important: the site must be served over HTTPS (GitHub Pages is suitable). PWA installation cannot be fully enabled from a file:// URL.

This does not create a native APK by itself; it makes the website installable like an app. A later Android/iOS wrapper can package the same web app as a store app if desired.
